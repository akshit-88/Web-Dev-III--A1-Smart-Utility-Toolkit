# Smart Utility Toolkit

Lab assignment for Web Dev III - using only core node modules (process, http, fs, crypto)

## How to run

Calculator:
node calculator.js add 10 5

isEven module reuse:
node app.js 7

Server:
node server.js
then go to localhost:3000/, /about, /contact

File manager (create/read/update/delete a file):
node fileManager.js

Dice roller:
node dice.js 5
